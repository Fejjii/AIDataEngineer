## Architecture deviations

- The slice creates the first DISCOVERY occurrence from `RECEIVED` without a preceding PLANNING occurrence. `LEGAL_TRANSITIONS` lists `RECEIVED → PLANNING` then `PLANNING → DISCOVERY`. PostgreSQL does not enforce that graph; DE002B orchestration still owns later PLANNING boundaries.
- Successful slice completion writes `COMPLETED` from the execution/validation application step rather than walking `EXECUTION → VALIDATION → … → DELIVERY → COMPLETED`.
- These shortcuts are slice-scoped. They do not change the published state-model document.
