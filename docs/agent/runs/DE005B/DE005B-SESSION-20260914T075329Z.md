## Important decisions

- Bootstrap writes use the DEV Snowflake user/key directly. Product
  `snowflake_dev` allow-list/`require_dev_namespace` was not weakened.
- `CREATE SCHEMA` is optional in the Python loader; `AIDE_DEV_RW` has
  CREATE TABLE on existing `VANTARA_RAW` schemas, not CREATE SCHEMA.
- v2 payment CSV row counts include planted late redeliveries. Load
  validation uses CSV line counts, not the grain `row_counts.json` value.
- `INFORMATION_SCHEMA.QUERY_HISTORY()` is invalid when the session database is
  `VANTARA_RAW`. Metrics/reconcile now use
  `SNOWFLAKE.INFORMATION_SCHEMA.QUERY_HISTORY()`. Partition/spill columns are
  not on that table function.
