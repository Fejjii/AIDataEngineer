## Scope completed

Persisted `RepairEvent` rows are now the authoritative repair budget. Before
propose, apply, or post-repair revalidation the Supervisor loads those events,
derives proposal/application/revalidation counts (including `task_id` for
per-task application limits), and enforces:

- `MAX_REPAIR_PROPOSALS = 2`
- `MAX_APPLIED_REPAIRS_PER_TASK = 1`
- `MAX_APPLIED_REPAIRS_PER_WORKFLOW = 1`
- `MAX_POST_REPAIR_REVALIDATIONS = 1`
- `MAX_RECURSIVE_REPAIRS = 0`

`InterviewResult.extra` only mirrors those persisted counts.

Read-only verifier assembly now:

- preserves `EvidenceReference.execution_mode` (no rewrite to Supervisor mode)
- sets `require_real_chain` from the workflow execution mode
- loads the persisted DRIFT `TwinObservation` for identity, authority, and
  freshness (`observed_at` / `fresh_until` at verification time)
- keeps `EvidenceDigest.sha256` as the persisted evidence-reference digest
- carries `claimed_sha256` from the immutable artifact body and compares it to
  hashes loaded from persisted repair proposal/application artifacts

A REAL workflow fails if required evidence is MOCK. Mixed REAL and MOCK always
fails. A MOCK workflow may remain fully MOCK.
