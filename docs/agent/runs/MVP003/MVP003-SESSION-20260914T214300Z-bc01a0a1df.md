## Important decisions

- Repair writer is pure patched-file construction. Supervisor applies it only
  through gateway `create_transformation` REPLACE of the generated file set.
- Drift injection lives in the composition root (`InvoiceStatusDriftInjector`).
  Supervisor depends on the `SchemaDriftInjector` protocol only.
- Column replacement is case-sensitive so `INVOICE_STATUS as invoice_status`
  becomes `STATUS as invoice_status`.
- Diagnostic execute with `ok=False` and `SCHEMA_MISMATCH` does not fail the
  workflow; it classifies and continues into propose/validate.
- EvidenceBundle is a reference manifest, not the MVP004 showcase report.
- No new policy `ReasonCode` values were added.
