## Important decisions

- `PermissionLevel` remains a string enum with comparison operators raising
  `TypeError` so membership is the only legal check.
- Connector registry does not import the capability registry (same-layer sibling
  isolation). R0 receives a permission map instead.
- SQL classifier fail-closes on parse/token/round-trip failure and unknown
  functions or constructs.
- Optional destructive/Git approval rejection skips the task and continues the
  originating phase; it does not use the fail-closed `FAILED` workflow row.
- `SecretProvider` is the architecture protocol name; scoped connector and LLM
  resolvers are views over it. No secret storage.
