- Four-way bounded reconciliation and deterministic fault-injectable side-effect fake.
- Serialized cancellation intent/ownership with connector I/O boundary outside the lock.
- Recovery ownership is bound to the workflow cancellation epoch; cancellation deterministically replaces ownership for tasks already reconciling while preserving attempt identity.
- Phase creation and reducer advancement reject cancellation and terminal states under the workflow advisory lock.
- Terminal cancellation verifies global task quiescence and exact unresolved-effect coverage, with a separate guarded path for cancellation with no unresolved effects.
- Cancellation restores the immutable historical attempt for an already `PARKED/AMBIGUOUS_OUTCOME` task, then either reconciles it under current cancellation ownership or records it in `unresolved_effects` before terminalization.
- Ordinary recovery cannot acquire or replace ownership while the workflow is `CANCEL_REQUESTED` or `CANCELLING`.
- Task claims reject terminal `COMPLETED`, `FAILED`, and `CANCELLED` workflows before creating an attempt.
- Stale worker completion preserves task/attempt state and emits best-effort `STALE_RESULT_REJECTED` evidence.
- Same-transaction monotonic audit and atomic budget reservation/settlement.
- Pinned contract availability parking and resume re-evaluation.
- PostgreSQL integration tests for the requested concurrency, recovery, cancellation, audit, budget, and rollback paths.
